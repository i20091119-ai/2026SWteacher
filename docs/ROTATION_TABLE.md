## 20h 초과 / 이월 예시

- 주간 상한은 **20시간** (모든 월 공통). 시트 `설정` 탭의 `weeklyCap` 값을 통해 조정 가능.
- 어떤 강사 A가 한 주(일~토)에 다음과 같이 배치됐다 가정:
  - 학교체험 해설 3h × 3회 = 9h
  - 가족체험 해설 주강사 3h + 보조 3h = 6h
  - 주말어드벤처 토오전 3.5h, 토오후 3.5h, 일오전 2h = 9h
  - 주 합계 = **24h** (실제 뷰: 빨강)
- 초과 = 24 − 20 = **4h** (해설로 간주)
- 보전 금액 = 4 × 30,000 = **120,000원**
- 다음 달 이월 권장 = 4 × 1.5 = **6h** → 다음 달 캘린더에 `연구(이월)` 또는 `지원(이월)`로 6h 편성.
- 장부 뷰에서는 해당 주의 해설을 20h 한도로 상한 처리 → 잘린 4h가 외부 장부에는 그대로 옮겨지지 않고, 다음 달 이월 항목으로 대체된다.
