## 14h 초과 / 이월 예시

- 어떤 강사 A가 6월 둘째 주(일~토)에 다음과 같이 배치됐다 가정:
  - 학교체험 해설 3h × 2회 = 6h
  - 가족체험 해설 주강사 3h + 보조 3h = 6h
  - 주말어드벤처 토오전 3.5h, 일오전 2h = 5.5h
  - 주 합계 = **17.5h** (실제 뷰: 빨강)
- 초과 = 17.5 − 14 = **3.5h** (해설로 간주)
- 보전 금액 = 3.5 × 30,000 = **105,000원**
- 7월 이월 권장 = 3.5 × 1.5 = **5.25h** → 7월 캘린더에 `연구(이월)` 또는 `지원(이월)`로 5.25h 편성.
- 장부 뷰에서는 해당 주의 해설을 (14 − 0) = 14h로 상한 처리 → 잘린 3.5h가 외부 장부에는 그대로 옮겨지지 않고, 다음 달 이월 항목으로 대체된다.
