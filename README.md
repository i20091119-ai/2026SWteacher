# 경남수학문화관 2026 SW해설강사 일정 관리

GitHub Pages(정적 프론트엔드) + Google Apps Script(시트 백엔드) 구조의 활동 일정 관리 웹앱.

## 빠른 시작

1. `docs/DEPLOY.md` 절차에 따라 OAuth 클라이언트 ID와 GAS 웹앱을 준비.
2. `js/config.js` 의 `GAS_ENDPOINT` 와 `GOOGLE_CLIENT_ID` 를 입력.
3. GitHub Pages로 저장소를 정적 호스팅.

## 디렉터리

- `index.html` / `css/` / `js/` — 정적 프론트엔드
- `gas/Code.gs` — Apps Script 백엔드 (시트 CRUD, 토큰 검증, 동시성 락)
- `docs/SHEET_STRUCTURE.md` — 구글시트 탭 구조
- `docs/DEPLOY.md` — 배포 절차
- `docs/ROTATION_TABLE.md` — 6~8월 순번 전개표 + 20h/이월 예시

## 핵심 개념

- **실제 활동 뷰 (A)**: 강사가 실제로 활동한 일정. 주 합계 20h 초과는 빨강 경고.
- **장부 뷰 (B)**: 외부 수당 장부에 옮겨 적을 화면. 주 단위로 (연구·지원) 우선 + 해설을 20h까지 상한, 잘린 해설은 다음 달 이월.
- **이월**: 잘린 해설 시수 × (30,000/20,000) = ×1.5 만큼을 다음 달에 `연구(이월)` / `지원(이월)` 로 편성하여 금액을 보전.
- **순번**: 가족체험SW(슬라이딩), 주말어드벤처(시간대 묶음 단순 순환). 학교체험SW는 순번 없음. 자동 배치는 없으며 **다음 차례 강사만 추천**.
- **인증**: 강사는 이름 선택, 관리자는 Google ID 토큰을 GAS 서버측에서 검증 후 화이트리스트 대조.
